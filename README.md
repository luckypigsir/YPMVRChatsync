# YPM VRChat Sync
首次运行请先安装依赖
YPMVRChatSync.exe项目地址：https://github.com/luckypigsir/YPMVRChatSync(NcmVRChatSync)/releases
基于 NcmVRChatSync 进行修改的适配 YesPlayMusic 的 VRChat 插件，可以将你在 YesPlayMusic 中播放的歌曲同步到 VRChat 聊天气泡中。
NcmVRChatSync项目地址：https://github.com/wling-art/NcmVRChatSyncV2/releases
项目介绍：可以将你在网易云音乐中播放的歌曲同步到 VRChat 聊天气泡中。
YesPlayMusic项目地址：https://github.com/qier222/YesPlayMusic/releases
项目介绍：一款第三方音乐播放软件，挂载网易云音乐，可登账号，轻量化低占用软件，只保留了必要的功能。

支持同步基本所有属性内容，同时可以使用文本构建真实进度条。

支持同步的内容：

- 歌曲名称
- 歌曲作者
- 播放进度
- 当前歌词
- 下句歌词

## 使用教程

1. 下载并运行 [YPMVRChatSync.exe](https://github.com/wling-art/NcmVRChatSyncV2/releases)
2. 使用软件内的按钮打开 YesPlayMusic
    - 也可以手动在 YesPlayMusic 快捷方式添加启动项 `--remote-debugging-port=9222`(添加方式：比如目标位置位于D:\\yesplaymusic\yesplaymusic.exe --remote-debugging-port=9222)
3. 点击开始同步
4. 打开 VRChat 游戏内 OSC 开关
5. 完成
